Modern C++ Testing Framework for Students & Developers

🚀 What is Catch2?

Catch2 is a modern, header-only testing framework for C++ that makes writing tests enjoyable and productive. Unlike traditional testing frameworks, Catch2 uses natural language expressions and requires minimal boilerplate code.

🎯 Header-Only

Just include one header file - no complex build configuration needed!

📝 Natural Syntax

Write tests that read like English using REQUIRE() and CHECK() macros.

🔧 Rich Output

Detailed failure messages that help you debug issues quickly.

⚡ Fast Compilation

Optimized for fast compilation and execution of test suites.

⚙️ Getting Started

Download Catch2

Download the single header file from GitHub or use a package manager:

# Using vcpkg
vcpkg install catch2

# Using conan
conan install catch2/3.4.0@

# Or just download catch.hpp directly

Include in Your Project

For the single-header version, just include it:

#define CATCH_CONFIG_MAIN  // This tells Catch to provide a main()
#include "catch.hpp"

Compile and Run

g++ -std=c++17 test.cpp -o test
./test

Your First Test

#define CATCH_CONFIG_MAIN
#include "catch.hpp"

TEST_CASE("Basic arithmetic operations") {
    REQUIRE(2 + 2 == 4);
    REQUIRE(5 * 3 == 15);
    REQUIRE(10 / 2 == 5);
}

TEST_CASE("String operations", "[strings]") {
    std::string str = "Hello";
    REQUIRE(str.length() == 5);
    REQUIRE(str + " World" == "Hello World");
}

Assertion Macros

TEST_CASE("Different assertion types") {
    // REQUIRE stops execution if failed
    REQUIRE(true);
    
    // CHECK continues even if failed
    CHECK(2 + 2 == 4);
    CHECK(3 * 3 == 9);
    
    // REQUIRE_FALSE for negative assertions
    REQUIRE_FALSE(1 == 2);
    
    // Exception testing
    REQUIRE_THROWS_AS(throw std::runtime_error("error"), std::runtime_error);
    REQUIRE_NOTHROW(2 + 2);
}

Organizing Tests with Sections

TEST_CASE("Vector operations") {
    std::vector<int> vec;
    
    SECTION("when empty") {
        REQUIRE(vec.empty());
        REQUIRE(vec.size() == 0);
    }
    
    SECTION("after adding elements") {
        vec.push_back(1);
        vec.push_back(2);
        
        REQUIRE(vec.size() == 2);
        REQUIRE(vec[0] == 1);
        REQUIRE(vec[1] == 2);
    }
}

Test Fixtures

class DatabaseTest {
public:
    DatabaseTest() {
        // Setup code
        db.connect("test_db");
    }
    
    ~DatabaseTest() {
        // Cleanup code
        db.disconnect();
    }
    
protected:
    Database db;
};

TEST_CASE_METHOD(DatabaseTest, "Database operations") {
    REQUIRE(db.isConnected());
    
    db.insert("key", "value");
    REQUIRE(db.get("key") == "value");
}

Parameterized Tests

TEST_CASE("Prime number testing") {
    int number = GENERATE(2, 3, 5, 7, 11, 13, 17, 19, 23);
    
    REQUIRE(isPrime(number) == true);
}

TEST_CASE("Range testing") {
    int value = GENERATE(range(1, 10));
    
    REQUIRE(value >= 1);
    REQUIRE(value < 10);
}

Matchers for Complex Assertions

#include "catch.hpp"

TEST_CASE("String matchers") {
    std::string text = "Hello World";
    
    REQUIRE_THAT(text, Catch::StartsWith("Hello"));
    REQUIRE_THAT(text, Catch::EndsWith("World"));
    REQUIRE_THAT(text, Catch::Contains("lo Wo"));
}

TEST_CASE("Floating point comparisons") {
    double result = 1.0 / 3.0;
    
    REQUIRE_THAT(result, Catch::WithinAbs(0.333333, 0.000001));
    REQUIRE_THAT(result, Catch::WithinRel(0.333333, 0.01));
}

Testing Algorithm Solutions

// Two Sum problem solution
std::vector<int> twoSum(std::vector<int>& nums, int target) {
    std::unordered_map<int, int> map;
    for (int i = 0; i < nums.size(); i++) {
        int complement = target - nums[i];
        if (map.find(complement) != map.end()) {
            return {map[complement], i};
        }
        map[nums[i]] = i;
    }
    return {};
}

TEST_CASE("Two Sum Algorithm") {
    SECTION("Basic case") {
        std::vector<int> nums = {2, 7, 11, 15};
        int target = 9;
        std::vector<int> expected = {0, 1};
        
        REQUIRE(twoSum(nums, target) == expected);
    }
    
    SECTION("Edge cases") {
        std::vector<int> nums1 = {3, 3};
        REQUIRE(twoSum(nums1, 6) == std::vector<int>{0, 1});
        
        std::vector<int> nums2 = {1, 2};
        REQUIRE(twoSum(nums2, 4).empty());
    }
    
    SECTION("Large input") {
        std::vector<int> large_nums(10000);
        std::iota(large_nums.begin(), large_nums.end(), 1);
        
        auto result = twoSum(large_nums, 19999);
        REQUIRE(result == std::vector<int>{9998, 9999});
    }
}

✅ Best Practices & Tips

🎯 Write Clear Test Names

Use descriptive names that explain what is being tested and expected behavior.

🔍 One Concept Per Test

Keep tests focused on testing one specific behavior or feature.

📊 Use Sections Wisely

Group related test scenarios using SECTION to reduce code duplication.

🏷️ Tag Your Tests

Use tags to categorize tests by speed, type, or component for easy filtering.

🚀 Performance Tips

• Use CHECK instead of REQUIRE when you want to see all failures
• Compile with -O2 for release testing
• Use BENCHMARK macro for performance testing
• Consider splitting large test files for faster compilation
